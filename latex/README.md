# PDF authoring rule

All published PDF reports are generated by **XeLaTeX** from versioned sources. Do not hand-edit exported PDFs, use Word/HTML print-to-PDF as the canonical workflow, or substitute a different body/font without review.

- `latex/research-report.sty`: shared A4/25mm/Latin Modern typography, plain tables.
- `latex/research-report.tex`: versioned LaTeX template containing the Pandoc body insertion point.
- `report/scheduling-pilot.md`: editable report content.
- `figures/*.svg`: vector figures.
- `Makefile`: deterministic conversion via Pandoc -> LaTeX -> XeLaTeX, including SVG -> PDF.

Run `make` from the repository root. Prerequisites: `pandoc`, `xelatex` with TeX Live Latin Modern, Python 3 and `cairosvg`. Generated `scheduling-pilot.pdf` and `build/` are outputs; review and publish only after verifying page renders, embedded fonts, text, figures, numerical data and all links.

Research results must come from primary measured data and retain original limitations. Do not change evidence merely for a cleaner layout.

Typographic house rule: use a simple hyphen `-` in ordinary prose, straight single quotes `'...'`, and nondecorative academic styling.
